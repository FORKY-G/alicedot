# 앨리스도트 프로젝트 관리 시안

`index.html`을 크롬 또는 엣지로 열면 바로 실행됩니다. 설치와 외부 라이브러리가 필요 없습니다.

## 포함된 기능

- 연도·월·작업상태별 조회와 프로젝트/거래처/담당자 검색
- 프로젝트 등록·상세 수정, 최초 등록일 고정
- 최초견적, 최종견적, 결제완료, 미지급금, 계산서 금액 집계
- 캔슬을 실매출 및 미지급금에서 제외
- 현재 조회 목록 CSV 내보내기
- 현재 브라우저에 시안 입력 내용 저장

현재 데이터는 모두 예시입니다. 실제 업로드한 엑셀의 회사 거래 자료는 포함되어 있지 않습니다.

예상매출은 최초견적 전체 합계이며 캔슬을 포함합니다. 실매출은 캔슬을 제외한 최종견적, 결제완료는 해당 상태의 최종견적, 미지급금은 결제완료·캔슬을 제외한 최종견적입니다. 계산서 합계는 입력된 계산서 금액입니다. 조회 기간 선택은 합계에 반영되며 검색·상태 필터는 목록에만 적용됩니다. 최종견적 미정은 0원과 구분해 표시합니다.

## GitHub에서 시안 열기

1. 시안용 GitHub 저장소에 `index.html`을 올립니다.
2. 저장소 Settings → Pages에서 배포할 브랜치를 설정합니다.
3. 배포가 완료되면 제공되는 주소로 접속합니다.

공개 Pages에 이 예시 화면을 올릴 수 있지만, 실제 회사 파일·거래내역·접속 비밀키를 소스에 넣지 마세요. 이 시안에는 로그인이나 사용자 간 동기화 기능이 없습니다. 브라우저별 데이터는 서로 별개입니다.

## 공동 사용 버전에 필요한 구성

프로그램 소스는 회사 소유 GitHub 저장소에서 관리하고, 실제 프로젝트 데이터는 인증된 사용자만 접근할 수 있는 공용 데이터베이스에 저장합니다. 사용자 역할에 맞춘 읽기·수정 권한, 동시 수정 충돌 처리, 변경 이력 및 백업을 연결한 뒤 실무용으로 전환합니다. Supabase Auth와 데이터 접근 정책을 적용하는 구성이 한 가지 선택지입니다.

이 파일은 기능과 화면을 검토하는 시안이며 공동 사용 서비스가 완성된 버전은 아닙니다.
